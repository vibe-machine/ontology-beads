# Questions

The questions Beads is meant to answer, and the query that answers each one. Installing the package stores them in the database as `StoredQuestion` and `StoredQuery` records.

1. What is recorded about this bead: its title, description, design, acceptance criteria, notes, type, status and priority? — no query yet
2. Who owns this bead, who holds it now, when was it created, started and closed, and why was it closed? — no query yet
3. Which beads are ready to start: open, nothing open in front of them, most urgent first? — no query yet
4. Which beads are blocked, and by which open beads? — no query yet
5. What does finishing this bead unblock? — no query yet
6. Which beads wait on a person's approval, and which approvals are still open? — no query yet
7. Which beads are being worked on right now, and who or which agent holds each one? — no query yet
8. Which beads are marked in progress but have gone quiet for a number of days? — no query yet
9. What is under this epic, at every level, and how much of it is closed? — no query yet
10. Which epic and which feature does this bead belong to? — no query yet
11. Which component does this bead belong to? — no query yet
12. Which beads break our tree rules: a task or bug directly under an epic, a feature under a feature, or an epic still open though every child is closed? — no query yet
13. Which beads carry a given label, or any one of several labels? — no query yet
14. Which open bugs are at priority 0 or 1? — no query yet
15. How many beads are in each status, and of each type? — no query yet
16. Which beads were created, or closed, in a given period? — no query yet
17. Which beads were discovered while working on this one, which beads are related to it, and which bead replaces it? — no query yet
18. What happened to this bead and when, and who did it: created, claimed, status changed, labelled, closed, reopened? — no query yet
19. What comments are on this bead, and by whom? — no query yet
20. Which beads belong to a wave, which wave, and what state is the wave in? — no query yet
