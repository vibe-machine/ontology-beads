# Beads

Beads 1.3.4, the issue tracker for planning work with agents: beads, their status, type, priority and labels, blocks and parent links, gates, leases, waves, history and comments. Answers what is ready, blocked, held, stale and under each epic.

This package was created by the Lingo Lab and has not been published: it has no remote. It follows the standard ontology package layout and depends on `gist >=5.0.0`.

- `schema/beads.tql` — the model's schema.
- `data/beads-schema-docs.tql` — type documentation, generated from the model's descriptions.
- `data/beads-provenance.tql` and `manifests/beads-v0.1.0.package-manifest.json` — generated provenance.
- `sandbox/` — sample data for the Lab's query sandbox, declared under `sampleData`; never installed with the package.
